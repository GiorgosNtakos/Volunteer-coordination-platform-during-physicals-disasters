# Πλατφόρμα Συντονισμού Εθελοντών

🔗 **EN English version:** [README.md](README.md)

Μια διαδικτυακή πλατφόρμα για τον συντονισμό εθελοντών, διασωστών και πολιτών κατά τη διάρκεια φυσικών καταστροφών.  
Το σύστημα υποστηρίζει διαχείριση αιτημάτων και προσφορών σε πραγματικό χρόνο, διαχείριση αποθήκης, ανάθεση εργασιών και οπτικοποίηση μέσω χαρτών.

Το έργο αναπτύχθηκε στο πλαίσιο εξαμηνιαίας εργασίας για το μάθημα  
**Προγραμματισμός & Συστήματα στον Παγκόσμιο Ιστό (World Wide Web)**.

---

## ✨ Λειτουργικότητες

### 👥 Ρόλοι Χρηστών

#### 🛠️ Διαχειριστής (Admin)
- Διαχείριση αποθήκης και κατηγοριών ειδών  
- Δημιουργία ανακοινώσεων  
- Παρακολούθηση αιτημάτων, προσφορών, οχημάτων και εργασιών μέσω διαδραστικών χαρτών  
- Προβολή στατιστικών στοιχείων του συστήματος με γραφήματα  

#### 🚑 Διασώστης (Rescuer)
- Συμμετοχή και διαχείριση οχημάτων  
- Φόρτωση και εκφόρτωση ειδών από την αποθήκη  
- Αποδοχή, ολοκλήρωση ή ακύρωση ανατεθειμένων εργασιών  
- Προβολή κοντινών εργασιών και οχημάτων στον χάρτη  

#### 🧑‍🤝‍🧑 Πολίτης (Citizen)
- Υποβολή αιτημάτων για είδη πρώτης ανάγκης  
- Δημιουργία προσφορών ως απάντηση σε ανακοινώσεις  
- Προβολή ιστορικού αιτημάτων και προσφορών

## 🧰 Τεχνολογίες που Χρησιμοποιήθηκαν

- **Backend:** PHP  
- **Frontend:** HTML, CSS, JavaScript

## ⚙️ Οδηγίες Εγκατάστασης (Τοπικά)

**1.** Εγκατάσταση **WAMP** (ή οποιουδήποτε περιβάλλοντος Apache + MySQL)

**2.** Κλωνοποίηση του αποθετηρίου στον web root φάκελο:
```text
wamp64/www/volunteer-coordination-platform
```

**3.** Δημιουργία βάσης δεδομένων MySQL

**4.** Εισαγωγή των αρχείων της βάσης δεδομένων:

- database/Schema.sql
- database/seeds/seed_demo.sql

**5.** Αντιγραφή του αρχείου ρυθμίσεων της βάσης δεδομένων:
```text
db_connect.example.php → db_connect.php

 Επεξεργαστείτε το αρχείο db_connect.php και συμπληρώστε τα στοιχεία σύνδεσης της βάσης δεδομένων
(host, όνομα βάσης, όνομα χρήστη, κωδικός).
Το αρχείο db_connect.example.php παρέχεται ως πρότυπο και δεν περιέχει πραγματικά στοιχεία σύνδεσης.
```

**6.** Εκκίνηση των υπηρεσιών Apache και MySQL

**7.**  Άνοιγμα της εφαρμογής στον φυλλομετρητή:
```text
http://localhost/volunteer-coordination-platform/Code
```

## 👤 Λογαριασμοί Δοκιμής (Demo Accounts)

ℹ️ **Σημείωση:**
Οι κωδικοί χρηστών στο αρχείο seed_demo.sql παρέχονται ως hashed τιμές ή εικονικά δεδομένα.
Για λόγους ασφάλειας, δεν περιλαμβάνονται πραγματικοί κωδικοί πρόσβασης στο αποθετήριο.

Μετά την εισαγωγή της βάσης δεδομένων, μπορείτε:

- **να δημιουργήσετε νέο χρήστη οποιουδήποτε ρόλου, ή**
- **να τροποποιήσετε χειροκίνητα τον κωδικό κάποιου χρήστη στη βάση δεδομένων.**

Η προσέγγιση αυτή διασφαλίζει την ασφαλή διαχείριση διαπιστευτηρίων, ενώ επιτρέπει τον πλήρη έλεγχο της εφαρμογής.
